# To-Do-List📝

A small desktop To-Do List application built with Electron, HTML, CSS and JavaScript.

The app allows users to add, remove and clear tasks through a simple pixel-art inspired interface.

## ✨ Features

- Add new tasks
- Remove individual tasks
- Clear all tasks
- Tasks are saved using `localStorage`
- Tasks remain available after restarting the app
- Custom pixel-art inspired UI
- Frameless Electron window
- Transparent window background
- Fixed window size
- Non-resizable window

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Electron
- LocalStorage
- Figma


## 🎨 Design

The application uses a pixel-art inspired visual style with a purple and pink color palette.

The interface is designed to be small and simple so it can function as a lightweight desktop widget.
